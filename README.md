# Birthday Wish

A delightful, interactive birthday website created for Mesoma, featuring animated wishes, playful games, and photo effects to celebrate her special day.

## ✨ Features

- **Personalized Birthday Message**: Custom birthday card with heartfelt wishes
- **Interactive Games**: Three fun mini-games to play:
  - Light candles by tapping flames
  - Catch floating balloons
  - Collect twinkling stars
- **Photo Effects**: Click photos to add sparkle and shimmer animations
- **Responsive Design**: Beautiful, mobile-friendly layout with smooth animations
- **Accessibility**: Proper ARIA labels and semantic HTML for screen readers

## 🎨 Design

- Modern glassmorphism design with soft gradients and backdrop blur
- Colorful pastel palette with pink, yellow, mint, and blue accents
- Smooth scroll behavior and reveal animations on scroll
- Floating particle effects and interactive button animations

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and accessibility features
- **CSS3**: Custom properties, gradients, animations, and responsive design
- **Vanilla JavaScript**: Interactive functionality without external dependencies

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - runs entirely in the browser

### Installation

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Enjoy the birthday celebration!

### File Structure

```
Birthday Wish/
├── index.html       # Main HTML structure
├── Style.css        # Styling and animations
├── Birthday.js      # Interactive functionality
└── Mesoma-2.jpg     # Additional photo
```

## 📸 Images

The website references two images:
- `Mesoma.jpg` - Main birthday photo
- `Mesoma 2.jpg` - Additional photo for the sparkle effect

Make sure these images are in the same directory as the HTML file for the full experience.

## 🎮 How to Use

1. **Read the Birthday Message**: Start with the personalized wish card
2. **Open Your Surprise**: Click the surprise button for additional wishes
3. **Play Games**: Use the birthday buttons to start interactive games
4. **Sparkle Photos**: Click on photos to add magical effects
5. **Reveal Secret Note**: Find the hidden message at the bottom
